# 銷售報表與 CSV

**分支範圍**　Sam 於 2026-11-24 選定銷售報表以期間、客戶、SKU 篩選並可匯出 CSV。此切片沿用現有訂單資料。頁面由「銷售管理 → 銷售報表」開啟。

## 資料口徑

- 一列是一筆銷售訂單明細。依訂單日期篩選，含開始與結束日期。可加客戶代碼、SKU 代碼作完整代碼比對，沿用資料庫的字元比對規則。查詢使用訂單保存的代碼與名稱。
- 納入已確認、部分履約、完成與關閉的訂單。明細金額取原訂單保存值，包含日後取消的餘量。已履約及已取消數量另以該明細的基本單位顯示。金額維持原幣，報表沒有跨幣別總額。
- CSV 與頁面查詢使用同一組已套用的篩選和 `sales.view` 權限。匯出涵蓋全部符合條件的分頁，最多 5,000 筆明細。超限會提示縮小範圍，使用者可依期間分次下載。CSV 以 UTF-8 BOM 編碼，文字欄位會防護試算表公式。

| CSV 欄位 | 內容 |
| --- | --- |
| `orderDate`, `orderNumber`, `status` | 訂單日期、編號、狀態代碼 |
| `customerCode`, `customerName`, `warehouseCode` | 客戶代碼、名稱及出貨倉代碼 |
| `skuCode`, `skuName`, `salesUomCode`, `quantity` | SKU 代碼、名稱、銷售單位及原訂購數量 |
| `unitSellingPrice`, `lineAmount`, `currencyCode` | 銷售單位的單價、原始明細金額及幣別 |
| `fulfilledBaseQuantity`, `cancelledBaseQuantity` | 已履約及已取消的基本單位數量 |

銷售績效需要發票／貸項／退款的口徑時，應使用財務來源。毛利另由共用功能負責人接 Inventory 出貨入帳成本。客退連結等 Returns 提供正式讀取介面。

實作沿用現有 Sales 權限與 CSV 文字防護。無資料表或 migration。
