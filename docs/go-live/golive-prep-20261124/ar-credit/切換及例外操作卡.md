# 應收貸項單｜切換及例外操作卡

供應收經手人、客戶退款經手人及財務覆核人員使用。文內客戶、單號及港幣金額均為合成資料。正式憑證及例外紀錄存放在公司的受控位置。

## 切換與日常操作

| 何時 | 誰做 | 操作及完成證據 |
| --- | --- | --- |
| 上線放行前及首筆貸項前 | 財務覆核、帳號管理員 | 以合成單據在預演環境走查建單、確認、他單核銷及解除、退款記錄及作廢，保存單號和前後餘額。確認查閱帳號有 `ar.view`，貸項經手人另有 `ar.credit.mgmt` 且看得到「新增貸項單」，退款經手人另有 `ar.refund.mgmt` 且看得到「新增客戶退款」。切換時按期初應收指引核對截數餘額及舊發票號。 |
| 收到經覆核的折讓或退貨貸項憑證 | 應收經手人 | 從已確認的原發票按「開立貸項單」，或在「應收貸項單」按「新增貸項單」後選原發票。核對客戶、原發票及幣別，填「貸項日期（必填）」及「原因（必填）」。逐行選「發票行（必填）」並填「貸項金額（HKD，必填）」。如有實物退貨，由退貨經手人完成過帳，再按憑證選「連結已過帳退貨單」及對應的「關聯退貨行」。「基本單位數量」供追溯，逐行上限按金額核對。按「儲存草稿」，記下草稿連結及憑證參考。 |
| 草稿需要更正或取消 | 應收經手人 | 在貸項詳情按「編輯草稿」，修正後按「儲存草稿」。如果毋須辦理，按「取消草稿」並確認。重開詳情核對行金額、原因或「已取消」狀態。 |
| 貸項可入帳 | 應收經手人、財務覆核 | 核對下文的逐行及整單上限，按「確認貸項單」並確認，記下正式貸項單號。系統以貸項金額與原發票當時未收額中較小的金額沖減原發票，餘款成為貸項可用額。若原發票已付清，整筆貸項成為可用額。重開原發票核對「未收額」及「貸項核銷記錄」，並在貸項詳情核對「已核銷」和「可用額」。 |
| 用可用額抵扣其他發票 | 應收經手人 | 在貸項詳情的「核銷至其他發票」，用「核銷發票（同客戶及幣別）」選另一張已確認且有未收額的發票。填「核銷金額（必填）」，金額須同時在貸項可用額及該發票未收額以內。按「執行核銷」，核對被核銷發票的未收額、貸項可用額及「其他發票」的有效核銷記錄。 |
| 他單核銷需要更正 | 應收經手人 | 在貸項詳情的「貸項核銷」找到類型為「其他發票」的那筆記錄，按「解除核銷」並確認。核對該筆顯示「已解除」，被核銷發票的未收額及貸項可用額均加回同一筆金額。 |
| 實際向客戶付出退款 | 退款經手人、財務覆核 | 實際付款後，在「客戶退款」按「新增客戶退款」，以「來源貸項單 *」選該客戶有可用額的已確認貸項。核對畫面的「可退款金額」，按憑證填「退款日期 *」、「退款金額 *」、「退款方式 *」及可用的「參考號」。按「建立草稿」，覆核後按「確認退款記錄」。確認退款時，系統按當時可用額再驗證，並在確認成功後扣減可用額。記下退款單號，核對貸項的「已退款」增加、「可用額」減少，並依公司流程對帳。記錄需要更正時，財務先核對實際款項，再按「作廢退款記錄」，填至少 5 字的原因並確認，核對同筆金額加回貸項可用額。 |
| 已確認的貸項需要作廢 | 應收經手人、財務覆核 | 先解除有效的他單核銷，再由財務覆核及作廢已確認的退款記錄。按「作廢貸項單」，填至少 5 字的原因，再按「作廢」。系統一併撤銷「原發票沖減」。核對「已作廢」狀態、保留的貸項單號及原發票加回的未收額。 |

### 怎樣核對可貸上限

一張貸項單只引用一張已確認的原發票。確認時，系統把每個原發票行金額先向下取至幣別小數位，再按剩餘小數尾數由大至小逐行補上最小幣值，直至各行合計等於原發票總額。尾數相同時，較前的行號優先。逐行上限扣除該行已確認的貸項金額後，是該行可再貸的金額。同一張草稿若有數行指向同一原發票行，須合計核對。整張原發票的已確認貸項連同這次擬確認的金額，亦不得超過原發票總額。

合成例子中，原發票兩行未取整金額均為 HKD 0.0149，發票總額為 HKD 0.03。兩行先各計 HKD 0.01。兩行尾數相同，餘下 HKD 0.01 分給第 1 行。因此第 1 行上限為 HKD 0.02，第 2 行為 HKD 0.01。第 1 行若已有 HKD 0.01 的已確認貸項，最多再貸 HKD 0.01。第 2 行填 HKD 0.02 會超過該行上限。港幣貸項金額填至小數點後兩位。

已登記及確認的期初發票如沒有明細行，使用畫面上的單一「期初發票貸項」，按 ERP 中登記的原發票總額扣除已確認貸項，核對剩餘可貸金額。

### 怎樣核對貸項、核銷與退款餘額

合成客戶 DEMO-C001 的原發票 DEMO-INV-001 為 HKD 100.00，收款已核銷 HKD 65.00，未收額 HKD 35.00。確認 HKD 50.00 的貸項 DEMO-CRN-001 後，原發票未收額為 HKD 0.00，貸項已核銷 HKD 35.00、可用額 HKD 15.00。再核銷另一張符合條件的發票 DEMO-INV-002 共 HKD 8.00，貸項可用額降至 HKD 7.00。實際付出 HKD 7.00 並確認退款記錄 DEMO-RFD-001 後，貸項應顯示「已核銷」HKD 43.00、「已退款」HKD 7.00、「可用額」HKD 0.00。原發票的收款核銷仍為 HKD 65.00。

## 例外處理

| 畫面提示或情況 | 處理方式 |
| --- | --- |
| 「請選擇已確認的原發票。」或找不到原發票 | 核對原發票號、客戶和狀態。舊單先以舊號核對已登記的期初發票。仍未找到或未完成切換核對的，保留憑證交財務跟進。 |
| 「貸項金額超過原發票或發票行的剩餘可貸金額」 | 在「應收貸項單」的「貸項單編號或客戶」輸入客戶，將「狀態」選為「已確認」，按「搜尋」，逐張核對「原發票」及相關行。按上文重算行及整單剩餘上限，修正草稿再確認。仍與憑證有差異時交財務覆核。 |
| 「原發票行或退貨來源不符，請重新選擇」 | 核對所選發票行，請退貨經手人確認退貨已過帳，且退貨行可追溯至該發票行。核對後重選。 |
| 「核銷金額不可超過貸項可用額或發票未收額。」、「核銷金額超過貸項單可用額」或「核銷金額超過發票的未收額」 | 重新載入兩張單據，核對最新的「可用額」及「未收額」。按兩者中較低的金額核銷，覆核是否已有同一筆核銷。 |
| 「原發票的沖減只能在作廢貸項單時撤銷」、「請先解除對其他發票的貸項核銷」或「請先作廢這張貸項單的退款」 | 在貸項詳情處理有效的他單核銷，請財務核對並更正退款，再作廢貸項。原發票沖減隨作廢一併撤銷。 |
| 「請先解除發票的核銷，或先作廢原發票的貸項單」或看不到「作廢發票」 | 在發票詳情核對「收款核銷記錄」及「貸項核銷記錄」。在「應收貸項單」按客戶搜尋已確認貸項，打開核對「原發票」。依財務核准次序解除相關核銷、作廢須更正的原單貸項，再處理發票。即使該貸項確認時原發票沖減為零，仍須先處理該貸項。 |
| 「退款金額超過貸項可用額」、「本頁沒有可退款的貸項單」或找不到來源貸項 | 檢查來源選單是否有其他頁，再回到貸項詳情核對客戶、狀態、「已核銷」、「已退款」及「可用額」。以最新可用額為上限，按實際已付金額登記。若實付超額，保留付款憑證及差異交財務對帳。 |
| 「資料已被修改，請重新載入後再試」、「資料正被其他操作更新，請重新整理後再試」或「單據目前的狀態不允許這個操作，請重新整理」 | 重新載入並覆核最新狀態、金額及操作記錄，再決定是否仍要處理。 |
| 「儲存結果尚未確認。請重送原操作。」或「操作結果尚未確認。請重送原操作。」 | 留在原瀏覽器分頁，以同一帳號按「重試確認結果」。若客戶退款出現「建立結果尚未確認。」或「操作結果尚未確認。」，按該頁「重試原操作」。若仍未確認或已離開原分頁，先按原發票、草稿連結及單號核對最新狀態和餘額，保留畫面交財務覆核後才再次入帳。 |

例外台帳逐筆記錄發生日期、時間及時區，經手人、覆核人、客戶代碼及幣別，原發票／期初舊號及發票行、已過帳退貨單及退貨行、貸項單號、被核銷發票號及退款單號，憑證參考、操作前後餘額、完整畫面提示、例外原因、處理結果及結案證據。若單號尚未取得，先記草稿連結。
