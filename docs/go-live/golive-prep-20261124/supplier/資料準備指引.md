# 正式供應商資料填寫指引

交付一份供應商清單，每列代表一家供應商。使用 [supplier-template.csv](supplier-template.csv)，刪除三列「合成示例」，保留第一列表頭。正式檔交給指定匯入人員，使用公司核准的受限位置。

| 欄位 | 怎樣填 |
| --- | --- |
| supplierCode、supplierName、defaultCurrencyCode | **必填**。唯一代碼如 DEMO-SUP-001（64 字）、名稱如「示例供應商」（190 字）、已啟用的三位幣別如 HKD。代碼大小寫或全半形不同仍可能重複。 |
| supplierId、displayName、paymentTermCode | 選填。只新增時 ID 必須留白，日後更新才用 ERP 正整數 ID（如 123）。顯示名如「示例甲」（190 字）。付款條款填已啟用的代碼，例如 NET30；先確認目錄。 |
| website、generalPhone、generalEmail、notes | 選填。分別如 https://example.test（500 字）、2123 4567（50 字）、demo@example.test（254 字）、一般備註（2,000 字）。勿在備註或 CSV 填銀行資料。 |
| addressLabel、addressPurpose | 有地址則兩欄必填，例如「採購地址」、ordering。用途可選 registered、office、ordering、return、remittance、other。地址名稱最多 100 字。 |
| addressLine1／2／3、city、stateRegion、postalCode、countryCode、addressPhone | 選填。addressLine1／2／3 可分填「示例路」「示例大樓」「示例室」。其餘依次如 Hong Kong、九龍、00123、HK、2123 4567。地址每行 190 字，城市／地區／郵編各 100 字，國別兩字母，電話 50 字。 |
| contactName、contactPurpose | 有聯絡人則兩欄必填，例如「示例聯絡人」（190 字）、orders。用途可選 general、orders、sales、accounts_payable、returns、emergency。 |
| jobTitle、department、contactEmail、contactPhone、contactMobile | 選填，例如採購主管、採購部、orders@example.test、2123 4567、9123 4567。職銜／部門 100 字，電郵 254 字，電話／手機 50 字。 |
| identifierType、issuerCountryCode、identifierValue | 選填，但使用時三欄一併填，例如 other、HK、DEMO-ID-003。類型可選 business_registration、company_registration、tax、other。國別兩字母，識別號最多 190 字。 |

**檔案及次序**　存為逗號分隔的 UTF-8 CSV，每檔預設上限為 10 MiB（10,485,760 位元組）及 10,000 筆，不含表頭。超任一上限就分檔，每檔保留表頭，跨檔也勿重複 Code。常見錯誤是停用幣別、電郵漏 @、用途填中文或只填地址／聯絡人其中一欄。代碼、電話、郵編、識別號設為文字，避免前導零消失。先啟用幣別及付款條款，再到「供應商匯入」選「只新增」、上載及預檢。

**畫面補錄**　CSV 每家只帶一組主要地址、聯絡人及識別資料。其他資料在詳情頁補，每項估計約 1–2 分鐘。銀行資料只由授權人員在銀行頁籤補，估計每家 2–3 分鐘。貨品與採購單位先建立，再到詳情「供貨關係」新增 SKU，選關係並按需填採購單位、商品代碼、最低量、交貨天數，估計每組 1–2 分鐘。

**核對與待確認**　預檢總數須等於來源筆數，逐條看警告及錯誤。確認後下載逐列結果，按 Code 核對已套用、失敗及略過的總數，抽查幣別、條款及狀態。不符時先查結果及供應商列表，只修正或重送未建立的列。請 Sam／採購先確認代碼規則、預設幣別／條款、哪些供應商須首日啟用及審批、哪些 SKU 關係必須先補。
