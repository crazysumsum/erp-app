# 採購切換日與錯收貨操作卡

**截數前｜採購主管、兩倉主管。** 按 Sam 核定時間停止舊單例行過帳，列出在途 PO、每行已過帳淨收、待過帳收貨、未收餘量。未過帳及去向不明的到貨先標記並分開待核。核對已收實物是否列入期初庫存，避免開帳後再收。逐張簽定唯一入帳路徑，通知兩倉。

| 指定路徑 | 採購和倉務的動作 | 完成證據 |
| --- | --- | --- |
| 舊系統結清 | 採購保留舊單，倉務按核准例外只在舊系統收貨。入庫後若實物要供新系統使用，先等庫存主管確認按核定方式銜接一次。 | 舊單、舊收貨單、倉庫批次、批准的庫存銜接紀錄。 |
| 新系統重建 | 採購鎖定或標記舊單禁止續收，只用未收餘量建新 PO，記錄新舊單號，按設定確認或交獨立審批。兩倉收到新單號後只按新單收貨。 | 新舊單號一對一、逐行未收量、入帳路徑及交接時間。 |

**放行｜採購主管＋兩倉主管。** 確認期初與實物對帳已簽。切換預演時兩倉各走一筆批次收貨；正式上線各倉首筆真實批次收貨，由倉務核對 PO 餘量、GR、庫存異動與結存，按倉庫／庫位／SKU／批號／效期／狀態核對基本單位。已過帳數量只出現一次。差異未清先停相關貨品及單據，交切換負責人裁定。需回退時先列出截數後已入帳單據，核定後再補記，避免重複過帳。

**錯收或結果不明｜倉務先停，主管覆核。**

1. 草稿填錯，改原草稿後重新核對；作廢的草稿走取消。逾時先查原收貨單和庫存異動，可用畫面原操作重試，勿另建同一收貨。
2. 已過帳才發現錯誤，先標記並分開實物，停止受影響批次領用或出貨。採購與庫存主管對清原 PO、GR、實物及異動。首期無收貨沖銷；主管核准後如需用庫存調整，只更正庫存，另登 PO／GR 差額並簽認後續可收量。
3. 實際退回供應商，由採購按現行系統外流程取得退貨確認，倉務登記實際離倉與核准的庫存處理，財務跟進相應憑證。

**例外須登記。** 時間、經手及覆核人、舊／新 PO、GR、原異動與更正異動號、倉／位／SKU／批號／效期／狀態、單位與正確／錯誤／差額數量、原因、實物去向、後續可收量及結案證據。
