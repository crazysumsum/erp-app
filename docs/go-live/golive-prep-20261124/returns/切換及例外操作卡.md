# 客戶退貨、退回供應商及退款操作卡

**使用時點**　退貨功能已放行、庫存成本已啟用後使用。實物退貨只追溯已有原始成本的出貨或收貨。成本啟用前的單據在 ERP 內無法退貨，交倉務及財務按切換例外處理。

**兩側均限原倉。** 客退收回原出貨倉，退供由原收貨倉出庫。貨在另一倉，先由倉務安排調撥或移交，到原倉核對實物後才過帳。已入 ERP 的庫存先完成正式調撥；尚未入帳的客退實物先移交原倉，再辦客退入庫。

## 實物退貨

| 何時 | 誰做 | 操作 | 完成證據 |
| --- | --- | --- | --- |
| 收到客戶退回的貨 | 原出貨倉倉務 | 開啟「退貨管理 → 客戶退貨 → 新增客戶退貨」。輸入原出貨單號，按「查找原單」。按實物填退貨日期、原因、原批次明細、原倉庫位及基本數量。核對畫面顯示的可退量，再按「建立草稿」。 | 詳情顯示「草稿」及客退單號，例如合成單 `CRT-1001`。核對原出貨單、SKU、批號、倉位及數量。 |
| 客退明細及實物已核對 | 有客戶退貨管理權限的倉務 | 在原草稿按「確認過帳」。客退一律入「隔離」，先留在隔離狀態等待檢驗。 | 重新讀取原單仍顯示「已過帳」，退貨明細為「隔離」。按原出貨倉、庫位、SKU 和批次核對隔離庫存增量。 |
| 客退貨品檢驗完成 | 有庫存調整權限的庫存人員 | 檢驗合格後由庫存走「狀態轉換」，將該批次核准數量由「隔離」轉為「可用」。不合格的數量繼續隔離，按庫存流程處理。 | 保存客退單、檢驗結果及放行紀錄。確認放行的數量只在原倉相應批次增加可用量。 |
| 確定要退貨予供應商 | 採購聯絡供應商，原收貨倉倉務建單 | 開啟「退貨管理 → 退回供應商 → 新增退回供應商」。輸入原收貨單號，按「查找原單」。填日期、原因、原批次明細、原倉實際出庫庫位、基本數量及該批庫存的狀態（可用、隔離或損壞），按「建立草稿」。 | 詳情顯示「草稿」及退供單號，例如合成單 `SRT-1002`。逐行核對原收貨、可退量及原倉實際可出庫存。 |
| 退供明細已核對，實際交運時 | 有退回供應商管理權限的倉務 | 在原草稿按「確認過帳」，保留交運／簽收憑證。財務其後按實際憑證處理貸項或退款。 | 重新讀取原單仍顯示「已過帳」。按原收貨倉、庫位、SKU、批次與狀態核對出庫數量，保存退供單號及交運憑證。 |

客退、退供的草稿尚未異動庫存。草稿填錯時按「取消草稿」，核對顯示「已取消」後再按正確資料建立。

## 退款記錄

| 何時 | 誰做 | 操作 | 完成證據 |
| --- | --- | --- | --- |
| 有實際退款憑證及已確認的貸項單，貸項仍有可用額 | 應收或應付退款經辦人 | 向客戶退回款項用「應收管理 → 客戶退款」。收到供應商退回的款項用「應付管理 → 供應商退款」。按「新增客戶退款」或「新增供應商退款」，選「來源貸項單」，核對往來方與幣別。填退款日期、金額、退款方式及參考號，按「建立草稿」。 | 退款詳情顯示「草稿」並可連回來源貸項單。合成例子為貸項可用 HKD 100.00、退款 HKD 40.00。 |
| 資金憑證及草稿已核對 | 有相應退款管理權限的財務人員 | 按「確認退款記錄」，在確認視窗再核對款項。ERP 登記退款記錄，實際付款或收款走財務既有流程。 | 狀態為「已確認」，顯示退款編號（合成例 `RFD-2026-000101` 或 `SRF-2026-000102`），來源貸項可用額減少。上例確認後剩 HKD 60.00。 |
| 退款記錄有誤 | 有相應退款管理權限的財務人員 | 草稿按「取消草稿」。已確認的記錄按「作廢退款記錄」，填寫至少 5 字的原因後確認。涉及實際資金差異，一併交財務處理。 | 顯示「已取消」或「已作廢」。作廢後原退款編號保留，來源貸項的可用額回補原金額。 |

兩側退款的來源都是**已確認且有可用額的貸項單**。實物退貨過帳後，貸項和退款由財務按實際憑證分別處理。

## 常見例外與畫面提示

| 情況或提示 | 當下怎樣做 |
| --- | --- |
| 查不到原單、畫面顯示「已沒有可退數量」，或提示「原出貨或收貨狀態不允許退貨」 | 核對原單號及逐行的出貨、收貨、沖銷及已退數量。仍有差異就先留貨、請原單負責人核對。 |
| 看不到目的庫位，或提示「客戶退貨只可收回原出貨倉」「退回供應商只可由原收貨倉出庫」 | 核對原單所屬倉、庫位是否有效。貨在別倉先安排調撥或移交，並保存移交或調撥單號。 |
| 「退貨量超過原單剩餘可退數量」 | 重查原單可退量以及已過帳退貨或沖銷。核對仍可退的批次及實物數量。需改草稿時，先確認原操作結果，取消舊草稿再建立正確明細。 |
| 「此異動缺少原始成本，無法過帳」 | 停止過帳，記下原出貨或收貨單及批次，交庫存與財務查核。確認是成本啟用前單據時，轉切換例外流程。 |
| 過帳逾時、斷線，或顯示「操作結果尚未確認。請重試同一個操作。」 | 留在原頁，按提示重試同一操作。退款頁使用「重試原操作」。若已離開頁面，先按原單及單號查狀態，再核對庫存異動或貸項可用額，確認後才續辦。 |
| 「退款金額超過貸項可用額」「來源貸項單必須已確認」，或下拉找不到貸項 | 到原貸項核對狀態、可用額及是否已被核銷或退款。收到明確的超額拒絕後，按最新餘額更正。已確認須保留原款項憑證供財務對帳。 |
| 實物退貨已過帳才發現批次、數量或庫位有誤 | 先標記並分開受影響貨品，交倉務主管及財務對清原單、退貨單、庫存異動及憑證，按核定方式處理。 |

**例外須登記。** 發生日期時間及時區、經手人及覆核人、客退／退供／退款類型、原出貨／收貨／貸項單號、相關退貨／退款／調撥／異動單號、畫面原文及當時狀態、倉／庫位／SKU／批號／庫存狀態／基本單位、申報數量與實物差異、退款幣別／金額／方式／憑證參考號、實物去向、處理決定、追蹤人及結案證據。正式紀錄留在公司受控位置，本卡只用合成數字及單號。
