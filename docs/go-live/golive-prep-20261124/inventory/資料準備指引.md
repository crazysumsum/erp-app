# 兩倉期初庫存｜資料準備指引

**要交什麼**　兩倉的倉庫／庫位對照清單，以及截數時點的[期初庫存 CSV](期初庫存範本.csv)。每列是一個「倉庫＋庫位＋SKU＋批次＋狀態」的實存數量。範本的 `DEMO-` 資料只供示範，交正式檔前請全部替換。

| 欄位 | 必填與填法 | 常見錯誤 |
|---|---|---|
| `warehouseCode` 倉庫代碼 | 必填。抄已啟用倉庫的代碼，如 `DEMO-W1`。 | 填倉庫名稱。 |
| `binCode` 庫位代碼 | 必填。用該倉內已啟用的庫位，如 `DEMO-B01`。 | 庫位屬於另一倉。 |
| `skuCode` 貨品代碼 | 必填。用已啟用且納入庫存管理的 SKU，如 `DEMO-SKU-EA`。 | 填條碼、品名或主商品代碼。 |
| `lotNumber` 批號 | 追蹤批次的 SKU 必填，如 `DEMO-LOT01`。不追蹤請留空。 | 同批寫成不同代碼；批號正規化後超過 100 UTF-8 位元組。 |
| `expiryDate` 到期日 | 追蹤批次且管效期的 SKU 必填，如 `2027-12-31`。只管批次可留空；不追蹤請留空。 | Excel 改成斜線日期；同一 SKU／批號填不同到期日。 |
| `stockStatus` 庫存狀態 | 必填，填 `AVAILABLE`（可用）、`QUARANTINED`（隔離）或 `DAMAGED`（損壞）。 | 填中文或把待判貨當可用。 |
| `baseQuantity` 基本單位數量 | 必填，填非負整數，如 `12`。零會列為略過。 | 填箱數、逗號、小數或負數。 |

**怎樣分檔**　另存 UTF-8 逗號 CSV，每檔最多 5,000 筆資料（零數量也計入；表頭另計）及 10 MiB。保留原表頭、欄位順序、空欄逗號及代碼前導零。建議按倉和庫位分檔。相同五欄組合先合計成一列；同一倉／庫位／SKU／批次的不同狀態放同檔，拆開可能在第二檔入帳時因已有存量或異動被拒。

**先建主資料**　貨品同事先建 SKU、基本單位、換算及批次／效期規則（序號追蹤不支援此匯入）。倉庫管理員到「倉庫與庫位」逐筆先建倉（代碼、名稱，地址／說明選填），再建庫位（代碼，名稱／說明選填）。CSV 不建立這些資料。清單備妥後，畫面輸入粗估每倉 2–3 分鐘、每庫位 30–60 秒，尚未實測。

**驗收**　管理員按檔案次序「上傳預檢」及確認入帳，記匯入編號並核對列數、略過列和錯誤。有共同批號的檔案請在上一檔入帳後，再預檢下一檔。錯誤先修來源再預檢，舊結果標記作廢。確認入帳後，以截數清單逐倉、庫位、SKU、批次及狀態比對庫存與異動，按 SKU／基本單位核對數量。差異先停，查原匯入結果；按照[切換操作卡](切換與例外操作卡.md)處理。

**請業務先定**　兩倉／庫位正式代碼、箱轉基本單位的對照、批次／效期缺漏及隔離貨歸類、兩倉實盤與覆核人。若需要序號、製造日、金額或成本，先向 PM 確認另行處理方式，請勿自行加欄。
