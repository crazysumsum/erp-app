# 兩倉期初庫存｜切換與例外操作卡

**何時可做**　Sam 定截數時間、兩倉負責人與放行人。期初結案 G3 需先完成發布，驗收及預演資料庫保留期初入口。正式庫只在兩倉對帳簽核後結案一次。

| 次序／負責人 | 怎樣做、怎樣確認 |
|---|---|
| 1．截數／Sam、兩倉負責人 | 到點先暫停庫存異動，保存同一截點的兩倉清單。截數後若有待收、出貨或調撥，記時間、舊單號、倉與數量，待 Sam 放行後補記一次。 |
| 2．匯入／庫存管理員 | 確認倉、庫位與貨品主資料就緒。逐檔預檢，對列數、跳過列、錯誤和檔案版本。由有庫存管理權限的人用已核准裝置及密碼確認整檔入帳，記下匯入與入帳操作編號。 |
| 3．雙倉對帳／兩倉覆核人、Sam | 逐倉、庫位、SKU、批次、狀態，比對截止實盤、ERP 結存及期初異動。數量以各 SKU 基本單位計，兩倉都零未解差異才交 Sam 簽核。 |
| 4．結案／庫存管理員 | 在「期初庫存」輸入**簽核當時的對帳版本**及至少 5 字的原因（可含簽核單號）。按「核對並結案」，核對確認視窗，用已核准裝置與目前密碼確認。版本已變就停，重新對帳並簽核，切勿用畫面最新版本直接替換。 |
| 5．放行／Sam、庫存管理員 | 重開頁面，確認顯示「庫存已上線，期初匯入已關閉」，看得到舊匯入結果、看不到上傳及入帳按鈕。保存結案人、時間、原因及版本；交 Sam 確認後恢復營運。 |

**每倉一份對帳及簽核紀錄**　截數日時／時區｜倉代碼｜來源檔名和版本｜匯入編號／入帳操作編號｜來源正數列／略過零列／已入帳列｜逐項「庫位、SKU、批號、到期日、狀態、基本單位、實盤、系統、差異、處置單號」｜對帳版本（兩倉對完後的同一版本）｜製表人／覆核人／Sam 簽名與時間。正式紀錄放內部受控位置。

**異常處理**　預檢錯誤或庫位鎖住，先停該檔；修正來源或由盤點負責人處理鎖，再重做預檢。結果不明時用原匯入編號查「已完成入帳」與操作編號，或重新讀取結案狀態，請管理員確認後才續辦。已入帳有差異時先凍結受影響貨位並通知 Sam。**結案單向，不提供重開或用期初 CSV 覆寫。** 結案後的漏批／錯量由授權人員走庫存調整，留原單、受影響項目、調整前後數量、原因、批准人及調整單號；差異處置後再對帳。
