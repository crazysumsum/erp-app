# 正式帳號資料準備指引

請交一份約 20 人的角色對照表，每列代表一名使用者的一個個人帳號。先複製 [角色對照表範本](./role-mapping-template.csv)，再移除三筆示範資料。填妥後走公司核准的私有管道交接。

| 欄位 | 必填 | 格式、範例與常見錯誤 |
|---|---|---|
| 帳號 | 是 | 3–190 字元，限英文字母、數字、句點、底線及連字號，例如 `demo-user-01`。不能以大小寫區分兩人。建帳後帳號名稱不能修改。 |
| 顯示名稱 | 建議填 | 最多 190 字元，可用中文，例如「示範銷售員」。選用同事能辨識的名稱，避免都填部門名。 |
| 部門／職務 | 是 | 例如「示範銷售／銷售員」，供主管核對。這欄只留在對照表。 |
| 核准角色 | 是 | 填核准表上的完整角色名稱，例如 `demo-sales`。多個角色用直線符號（`\|`）分隔。採購建單與批准由不同帳號操作。 |
| 開通批次 | 是 | 填 1–4，例如 `1`。每批約 5 人，按值班安排排入。這欄只留在對照表。 |
| 備註 | 否 | 例如「示範資料」。只填開通安排，密碼、裝置金鑰等憑證另行私下保管。 |

**檔案與建帳順序**　保留表頭，存成 UTF-8 CSV。約 20 列可放同一檔，再按批次開通。使用者與角色管理在 `main c6df403e` 沒有 CSV 匯入、預檢入口或上傳上限。先完成正式庫更新與首位管理員設備核准，由管理員在「角色管理」建立和核對角色權限，再於「用戶管理 → 新增用戶」逐筆輸入帳號、顯示名稱、初始密碼及角色。每人建帳、設備核准與首登改密，合計估計 2–3 分鐘的人工作業。

**驗收與更正**　副管理員逐筆比對帳號名單、角色和批次；使用者改密後重新登入，核對應看到的工作頁。缺漏或角色不符，先暫緩該帳號交接，由管理員在用戶頁補建或修正角色，再由副管理員核對。帳號拼錯時，停用錯誤帳號並重建正確帳號，保留更正紀錄。

**需先確認**　請 Sam 或部門主管確認正式人員、帳號命名、每人的角色、採購建單與批准的分工、四批時段，以及正副管理員和正式佈署負責人。

**範本驗證**　三筆合成資料已在本機讀回並通過欄數、帳號格式及唯一性檢查。ERP 沒有帳號 CSV 預檢入口，因此採逐筆建帳驗收。
