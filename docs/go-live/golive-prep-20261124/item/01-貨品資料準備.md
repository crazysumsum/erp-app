# 正式貨品資料準備

先交[分類及品牌清單](item-catalog-preparation-template.csv)，再交**全部 SKU 清冊**，含下表業務欄位及包裝換算、條碼、效期、多規格組合。Standard 使用 [SKU CSV](item-import-template.csv)，一列是一個商品及其唯一 SKU；多規格留在清冊供畫面建檔。兩份範本的合成列在正式送件時刪除。

**第一步｜先建立目錄。** 在「商品管理 → 商品分類」先建上層再建子分類；「品牌」填品牌名稱；「計量單位」建並啟用基本與包裝單位。這些目錄沒有批量匯入畫面，分類及品牌清單供人工逐項建檔。SKU CSV 預檢只查分類名稱、品牌名稱、基本單位代碼。Variant 建檔前另在「商品屬性」建選項，並在「商品分類」配置屬性，CSV 不查或建立屬性。CSV 請直接複製畫面名稱或代碼。系統忽略英文字母大小寫及欄位前後空白，字中空格及全／半形要一致。若不同上層有同名分類，CSV 無法指定路徑，該 SKU 請在畫面選正確分類。

| CSV 欄位 | 首次建檔必填 | 格式、例子與常見錯誤 |
| --- | --- | --- |
| `skuId` | 留空 | 系統內部數字 ID。首次建檔不要填舊系統 ID 或 SKU 代碼。 |
| `expectedSkuVersion` | 留空 | 系統目前版本號。僅更新時與 `skuId` 一起填，例如 `3`。 |
| `skuCode` | 是 | 公司內唯一文字，最多 190 字，例如 `DEMO-ITEM-001`。保留前置零，大小寫不同也可能重複。 |
| `skuName` | 是 | SKU 顯示名稱，例如「合成範例批次款」。 |
| `itemName` | 是 | 商品名稱，例如「合成範例批次商品」。同名不會把多列組成 Variant。 |
| `categoryName` | 是 | 已建分類名稱，例如「合成範例分類」，勿填分類路徑。 |
| `brandName` | 是 | 已建品牌名稱，例如「合成範例品牌」，勿填官方名稱。 |
| `defaultTrackingPolicy` | 按貨品確認 | `none` 無批次、`batch` 批次、`batch_expiry` 批次及效期。留空預設 `none`。首期勿用 `serial`。 |
| `suggestedPriceAmount` | 否 | HKD 建議價，例如 `12.5000`。最多 15 位整數及 4 位小數，不加貨幣符號或千位逗號。 |
| `purchasable` | 建議明填 | `true` 可採購或 `false` 不可採購。留空為 `true`。勿填「是／否」或 `1/0`。 |
| `sellable` | 建議明填 | `true` 可銷售或 `false` 不可銷售。留空為 `true`。勿填「是／否」或 `1/0`。 |
| `baseUomCode` | 是 | 填已啟用的基本單位代碼，例如 `EA`，勿填顯示名稱「件」。 |

2. **存檔。** UTF‑8 逗號分隔 `.csv`，保留表頭。文字包含逗號時用雙引號包住，代碼欄用文字格式。每次一檔，上限 20 MB（20,000,000 bytes），預設最多 10,000 資料列。約 2,000 列可同檔，先小批試匯，正式檔可按分類分批核對。
3. **預檢再匯。** 到「商品管理 → 匯入／匯出」選「只新增」。若預檢找不到分類、品牌或單位，對照清單補建缺項或改 CSV 錯字；分類同名有歧義時用畫面建該 SKU。任一列失敗整批不能執行，修正後重傳。逐項確認警告後才確認匯入並下載結果。CSV 建立的是草稿。
4. **補錄後才啟用。** 在 SKU 詳情設整數包裝換算（如 `1 BOX = 24 EA`）、條碼及對應單位。`batch_expiry` 填正整數保存天數，最短到貨／銷售天數不可超過保存天數。實際批號和到期日填期初庫存檔。Variant 選「新增商品 → 多規格」，選屬性及組合，再逐個填 SKU；既有 Variant 從商品詳情新增。估包裝／條碼／效期每 SKU 2–4 分鐘，Variant 另估 3–5 分鐘。
5. **對帳才交 Inventory。** 保存每檔工作編號、列數及結果。用 SKU 匯出核對唯一代碼、筆數、基本單位及啟用狀態，另核對手補欄位。與 Inventory 確認兩倉每筆期初 SKU 存在，基本單位、批次／效期政策一致。有差異先暫緩受影響項，修正後再核對。已成功的批次避免重送。

**請業務確認**　清冊交付日、分類樹及各 SKU 歸屬、同名分類處理、品牌正式名稱與舊別名、SKU 代碼及前置零、基本單位及箱入數、條碼與效期政策、Variant 屬性組合、應啟用品項及兩倉覆核人。
