# 應付人員角色配置

帳號管理員在「角色管理」按職務配置，財務主管覆核分工，再用獲核准的裝置以一般帳號實測。角色名稱可按公司命名慣例調整。

| 職務 | 權限 | 可做的事 |
| --- | --- | --- |
| 應付查閱（示例角色 `demo-ap-viewer`） | `ap.view` | 查閱應付發票、付款及帳齡。 |
| 入帳（`demo-ap-invoice`） | `ap.view`、`ap.invoice.mgmt`、`purchasing.view`、`supplier.view` | 從已確認收貨登記、修改及確認發票，按流程取消草稿或作廢。使用供應商篩選收貨，或選啟用供應商登記無採購單發票。 |
| 付款及核銷（`demo-ap-payment`） | `ap.view`、`ap.payment.mgmt` | 由帳齡列或應付發票登記既有債務的付款，並確認、核銷、解除或按流程作廢。 |
| 付款人員需登記預付款 | 在付款角色另加 `supplier.view` | 搜尋供應商及可用幣別。無同幣別未付發票時，預付款只可付給啟用中的供應商。 |
| 獲授權調整發票行金額（`demo-ap-invoice-override`） | 在入帳權限另加 `ap.invoice.price.override` | 按原發票調整收貨行金額並填理由。一般入帳角色可加真實正數費用行。 |

**供應商資料可見範圍**　`supplier.view` 可查供應商主檔和遮蔽後的銀行帳戶清單。查看完整帳號另須 `supplier.bank.view`。應付角色不需配置銀行查看或維護權限。

**交接驗收**　先用入帳帳號確認可選已確認收貨和啟用中的供應商。付款帳號由未付發票帶入供應商及幣別並完成登記，需辦預付款的人員再驗證供應商搜尋。以一般入帳帳號確認改價功能不可用，再由授權帳號驗證可輸入實際行金額及原因。使用 [正式帳號資料準備指引](../userrole/account-preparation.md) 的角色對照表登記實際分工。
