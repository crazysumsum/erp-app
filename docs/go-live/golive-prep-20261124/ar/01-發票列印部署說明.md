# 發票列印部署說明

請部署人員在正式環境的 ERP 後端服務填入以下四項設定。正式公司及付款資料請經內部管道交給部署人員。

| 環境變數名稱 | 是否必填 | 填寫內容 |
| --- | --- | --- |
| `AR_INVOICE_COMPANY_NAME` | 必填 | 公司法定名稱，單行，最多 190 字。 |
| `AR_INVOICE_COMPANY_HEADER` | 選填 | 抬頭補充資料，例如地址、聯絡方法，可分行。 |
| `AR_INVOICE_PAYMENT_INSTRUCTIONS` | 必填 | 付款方法及所需資料，可分行。 |
| `AR_INVOICE_FOOTER` | 選填 | 發票底部文字，可分行。 |

多行欄位各最多 2,000 字。每行以 Enter 真正換行。以下是合成資料的填寫示意。

```dotenv
AR_INVOICE_COMPANY_NAME="QA 示範公司"
AR_INVOICE_COMPANY_HEADER="合成地址第一行
合成地址第二行"
AR_INVOICE_PAYMENT_INSTRUCTIONS="測試付款說明第一行
測試付款說明第二行"
AR_INVOICE_FOOTER="僅供演示"
```

儲存設定後，請部署人員重新啟動所有 ERP 後端服務實例，使它們讀取新值。用 Chrome 開啟一張已確認的測試發票並預覽 A4，核對公司名稱、付款資料、換行及每頁的發票號碼與頁次。重印會使用後端目前的公司設定，客戶名稱及帳單地址沿用確認開票時保存的內容。

列印發票請使用 Chrome 或 Edge。其他瀏覽器列印時不會有每頁的發票編號及頁碼。

缺公司名稱或付款資料時，列印頁會指出未設定的項目並暫停列印。選填項目留空時，該區塊會省略。上線前請為會開票的客戶補齊**預設帳單地址**，否則確認發票時會要求補上，原單仍保留為草稿。
