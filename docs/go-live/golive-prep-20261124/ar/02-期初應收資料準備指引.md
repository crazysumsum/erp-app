# 期初應收資料準備指引

請財務用[期初應收清單範本](期初應收清單範本.xlsx)，把截數時仍有未收餘額的舊發票逐張列出。每張一列。填寫前請清除合成示例列。

| 欄位 | 怎麼填 |
| --- | --- |
| 客戶代碼、幣別 | 填 ERP 客戶代碼及該筆應收的原幣代碼，例如 HKD。 |
| 舊發票號碼 | 按舊系統匯出值保留原號，包括前導零。此欄已設為文字。 |
| 原發票日、原到期日 | 兩個日期均填 `YYYY-MM-DD`，沿用舊發票上的日期。 |
| 截數時未收餘額、備註 | 填截數當刻以原幣計算的正數未收餘額。備註選填。 |

## 截數及核對

1. **訂定截數時點。** 由財務確認日期、時間及時區，據此判定哪些已開發票仍有欠款。
2. **保留來源清單。** 留存舊系統在該時點匯出的未收發票清單，供登記和對帳。
3. **切換收款入帳。** 截數後的收款一律在 ERP 入帳，按對應的期初發票核銷。舊系統在截數時停止登記這些收款。
4. **舊出貨不載入。** 在 ERP 逐張登記期初發票，沿用舊號作對帳依據。
5. **核對及簽認。** 逐張核對客戶、幣別、舊號、日期及餘額。再按客戶及幣別核對帳齡表的張數、餘額合計，並由指定財務人員簽認。合計須與來源清單對在同一截數時點。

## 請財務先回覆的四點

1. 最長的舊發票號碼有多少字？
2. 有沒有只差大小寫或空格的號碼？請留意前後及中間空格。
3. 舊發票號碼在全公司是否唯一？
4. 同一客戶跨年度有沒有重複號碼？

清單齊備後，以單人逐張登記估算，約每張 1 至 1.5 分鐘，100 張約 2 小時。整理清單、處理差異和簽認時間另計。填錯時請填寫原因、作廢並重新登記。若已核銷，先請有權人員解除核銷，重登後按原收款重新核銷。
