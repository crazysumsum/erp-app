# 應付貸項單｜切換及例外操作卡

供應付入帳、退款經手及財務覆核人員使用。文內供應商、單號和金額均為合成資料。正式憑證及例外紀錄存放在公司的受控位置。

## 切換與日常操作

| 何時 | 誰做 | 操作及完成證據 |
| --- | --- | --- |
| 上線放行前及首筆貸項前 | 財務覆核、帳號管理員 | 先在預演環境用本卡的合成單據走查，保存原發票、貸項及餘額核對結果。正式使用前，確認經手人看得到「應付發票」及「應付貸項單」，有權按「建立貸項單」。退款經手人另須有供應商退款管理權限。上線前的舊發票留在原有受控台帳跟進。 |
| 收到供應商貸項文件或確認可扣款 | 應付貸項經手人 | 在「應付發票」打開已確認的原發票，按「建立貸項單」。核對供應商與幣別，填貸項日期、原因及手上有的供應商貸項單號。每一貸項行選一個原發票行，填該行金額。若要連結已過帳的退回供應商單，請退貨經手人提供對應的「退回供應商單 ID」和「退貨行 ID」，核對它們屬於該原發票行的收貨來源。「基本數量」供查閱及追溯。按「建立貸項草稿」，記下草稿連結及原件參考。 |
| 草稿需要更正 | 應付貸項經手人 | 在貸項單詳情按「編輯草稿」，改妥後按「儲存草稿」。草稿若已無需辦理，按「取消草稿」。重開詳情核對行金額、原因或「已取消」狀態。 |
| 貸項可入帳 | 應付貸項經手人、財務覆核 | 按下文核對行上限與整張原發票上限，再按「確認貸項單」。記下正式貸項單號。系統先沖減原發票當時的未付額。重開兩張單據，核對原發票未付額及「貸項核銷」，並在貸項詳情核對「已核銷」和「可用額」。原發票當時已付清時，整筆貸項成為可用額。 |
| 用餘額抵另一張發票 | 應付貸項經手人 | 在貸項詳情的「核銷其他發票」中，從「被核銷發票」選同供應商、同幣別的已確認未付發票。核銷金額須同時在貸項可用額及該發票未付額以內。按「核銷貸項」，保存被核銷發票號，核對兩邊餘額及有效核銷記錄。 |
| 他單核銷需要更正 | 應付貸項經手人 | 在貸項「核銷記錄」找對應他單那筆，按「解除核銷」並確認。核對該筆顯示「已解除」，貸項可用額和被核銷發票未付額均加回原核銷額。 |
| 確認後的貸項需要作廢 | 應付貸項經手人、財務覆核 | 先解除有效的他單核銷，並由財務覆核及更正有效的退款記錄。在貸項詳情按「作廢貸項單」，填至少 5 字的原因並確認。系統一併撤銷原發票的貸項核銷。重開詳情，核對狀態「已作廢」、保留的原貸項單號及回復的原發票未付額。 |
| 實際收到供應商退款 | 供應商退款經手人、財務覆核 | 在「供應商退款」按「新增供應商退款」，選已有可用額的已確認來源貸項單。填實際收款日期、金額、方式及手上的憑證參考，按「建立草稿」，覆核後按「確認退款記錄」。記下退款單號，核對貸項的「已退款」增加、可用額減少。退款記錄若須更正，於退款詳情按「作廢退款記錄」，填原因並確認，核對同筆金額加回貸項可用額。銀行收款按公司原有流程對帳。 |

### 怎樣核對可貸上限

同一張貸項單只引用一張已確認的原發票。確認時，系統會按原發票行分配上限，並檢查該發票及各行已確認的累計貸項。各行金額先捨去超出幣別小數位的部分，再按小數尾數由大至小分配差額。尾數相同時，行號較前的優先。

合成例子中，原發票兩行各為 HKD 10.0050，發票總額 HKD 20.01。第 1 行上限為 HKD 10.01，第 2 行上限為 HKD 10.00。第 1 行若已有 HKD 6.00 的已確認貸項，該行最多再貸 HKD 4.01。貸項行填幣別允許的小數位，港幣填至兩位。

### 供應商發票已扣退貨

退回供應商處理的是實物，退回的數量記在退貨單。從收貨開應付發票時，按整張已確認收貨的實收數量入帳。已確認發票的退貨扣減由財務另開應付貸項單處理。

| 供應商文件 | 入帳人員怎樣對齊 | 完成證據 |
| --- | --- | --- |
| 供應商發出的發票已按行扣款，該筆金額直接反映在發票上 | 在確認應付發票前，請有發票改價權限的人對照原件，於發票草稿改對應的「發票金額」並填「改價原因」。按原件輸入「供應商發票總額」，核對畫面總額後確認。 | 合成例子中，整張收貨的發票行原計 HKD 325.00，原件按該行扣 HKD 25.00。對應發票行填 HKD 300.00，保留實收數量。核對 ERP 發票總額 HKD 300.00，並把 HKD 25.00 標記為已在發票處理。 |
| 原發票為全額，供應商另發貸項文件 | 按全額原發票的憑證入帳，再由已確認的原發票開應付貸項單，填扣款金額及供應商貸項單號。已確認發票的後續扣減也走貸項單，由財務覆核憑證。 | 合成例子中，保留 HKD 325.00 原發票及 HKD 25.00 已確認貸項。若原發票確認貸項前尚欠 HKD 10.00，確認後其未付額是 HKD 0.00，貸項可用額是 HKD 15.00。兩張單號及原件可交叉核對。 |

同一筆扣減只採一條入帳路徑。若原件只列整單淨額、無法核實應扣哪一行，先保留草稿及原件，請財務覆核後再入帳。

以上表第二例的 HKD 15.00 可用額為例，另核銷一張符合條件的發票 HKD 8.00，實際收回供應商退款 HKD 7.00 並確認退款記錄後，貸項詳情應顯示已核銷 HKD 18.00、已退款 HKD 7.00、可用額 HKD 0.00。

## 例外處理

| 情況 | 處理方式 |
| --- | --- |
| 找不到原發票、原發票尚未確認或屬上線前舊帳 | 先憑原件核對單號和入帳路徑。ERP 貸項以已確認的 ERP 原發票及其發票行為來源。舊帳交財務循原受控台帳跟進。 |
| 貸項金額超過原發票或發票行的可貸上限 | 查同張原發票的已確認貸項，逐行核對累計及到幣別小數位的上限。修正草稿金額後再確認。若原件與分配仍有差異，保留草稿及原件交財務覆核。 |
| 退貨單或退貨行與原發票不符 | 請退貨經手人核對退貨單已過帳、退貨行屬於該單，並追溯至原發票行的收貨來源。核對後重填連結。 |
| 原發票沒有「作廢發票」，或作廢被拒 | 查發票詳情的「付款核銷」和「貸項核銷」，並按「查看原發票貸項單」查已確認的關聯。仍有有效核銷或已確認的原單貸項時，先依財務核准的更正次序解除核銷及作廢貸項。即使原單貸項在確認時沖減為零，仍須處理該貸項。 |
| 貸項無法作廢，或無法單獨解除原發票的那筆核銷 | 先處理他單的有效核銷與有效退款。原發票的貸項核銷在作廢貸項時一併撤銷。涉及已收到的款項時，先由財務按銀行憑證覆核退款更正。 |
| 退款金額超過可用額，或找不到來源貸項 | 重新載入貸項，核對最新狀態、核銷、已退款及可用額。以已確認貸項的可用額為上限登記實際收款。若款項仍有差異，保留憑證交財務對帳。 |
| 操作逾時或結果尚未確認 | 同一帳號回到原瀏覽器分頁，按「重試原操作」。若已確定收到業務拒絕，依提示修正再送。若仍未確認，先查原單號、狀態及餘額，保留畫面交財務覆核。 |

例外台帳逐筆記錄發生日時及時區、經手人、覆核人、供應商代碼及幣別、原發票及行號、收貨及退貨單／行、貸項單、被核銷發票或退款單、供應商原件或收款憑證參考、操作前後餘額、錯誤提示、原因、處理結果及結案證據。若某個單號尚未取得，先記草稿連結。
