# Sales 未交付訂單 CSV 準備指引

請交切換時**完全未出貨、確定由 ERP 接手**的訂單。每列是一項貨品明細，同一張單的前 12 欄必須相同。部分已出貨的舊單整張留舊流程結清。複製 [CSV 範本](sales-open-orders-template.csv)，刪除所有合成列再填正式資料。

| 欄位 | 必填 | 格式、例子及常見錯誤 |
| --- | --- | --- |
| `templateVersion` | 是 | 固定 `1.0`。試算表勿改成 `1`。 |
| `sourceOrderKey` | 是 | 同一張 ERP 訂單各列用同一組鍵，如 `SYN-SO-001-A`，最多 190 字。兩倉子單用不同鍵。 |
| `channelCode` | 是 | 填營運已開通的代碼，如合成用 `SYNTHETIC`。1–50 字、大寫英數及底線、首字母大寫。 |
| `externalOrderId` | 是 | 來源訂單號，如 `SYN-OLD-001-A`，最多 190 字。同渠道不可重用，重送沿用原值，保留前置零。 |
| `customerId` | 是 | ERP 客戶數字 ID，如 `990001`。勿填客戶名稱或代碼。 |
| `warehouseCode` | 是 | 啟用的出貨倉代碼，如 `SYN-WH-A`，最多 50 字。勿填庫位或倉名。 |
| `orderDate` | 是 | `YYYY-MM-DD`，如 `2026-11-24`。勿用斜線或試算表日期序號。 |
| `requestedDeliveryDate` | 否 | 如 `2026-12-15`，不可早於訂單日。未知留空。 |
| `currencyCode` | 是 | 已啟用的三字大寫幣別，如 `HKD`。勿填貨幣符號。 |
| `paymentTermCode` | 否 | 已啟用的付款條款代碼，如 `NET30`（須實際存在），最多 50 字。空白表示未指定，不會自動帶客戶預設。 |
| `customerPoReference` | 否 | 客戶採購單號，如 `SYN-PO-001`，最多 190 字。勿用來代替外部訂單號。 |
| `orderNotes` | 否 | 訂單備註，如「合成範例」，最多 2,000 字。同一張單各列須一致。 |
| `skuCode` | 是 | 可銷售 SKU，如 `SYN-SKU-A`，最多 190 字。勿填品名、條碼。 |
| `salesUomCode` | 是 | 該 SKU 已啟用的銷售單位，如 `EA`，最多 100 字。勿把「箱」當通用代碼。 |
| `quantity` | 是 | 大於零、最多六位小數，如 `2`。換算成基本單位後必須為整數。 |
| `unitSellingPrice` | 是 | 每個銷售單位的單價，如 `1.2500`，非負、最多四位小數。零價須人工覆核。 |
| `lineNote` | 否 | 明細備註，如「合成明細」，最多 500 字。同 SKU／單位重複列若單價或備註不同，整張單會被拒。 |

**檔案與次序。** 用 UTF-8 逗號分隔的 `.csv`，保留英文表頭，選填欄留空。先將編號欄設為文字，數量及單價勿用千位逗號或科學記號。系統每檔最多 50 MiB、100,000 筆明細、10,000 張單，每單 100 列。若環境設較低上限依該值。建議按倉分檔，同一張子單的明細放同檔。先完成客戶、貨品及單位、幣別／條款、倉庫、庫位與期初庫存，再由有匯入權限的同事上傳。請管理員先確認正式渠道代碼及匯入排程已啟用。

**逐筆補錄。** CSV 沒有送貨地址、聯絡人或帳單地址。Customer 同事先在客戶畫面補錄（估計每客戶 2–4 分鐘），要開票須有預設帳單地址。庫位、批次及效期由倉庫在履約時核對（估計每筆 1–2 分鐘）。匯入確認會建單並嘗試預留，這些資料應事前補妥。特殊送貨要求先按手工流程核對。

**核對與修正。** 上傳後先比兩倉的張數、明細、SKU／基本單位數量、幣別與金額。打開例外核對行號、欄位和重複對應的舊單，差異未解前停在預檢。確認後下載批次結果，逐筆對上來源單及 ERP 單號。只處理確定未成功的單，保留原渠道及外部單號。結果不明時先查批次與現有訂單。

**請 Sam／業務先確認。** 截數時間、由哪個來源交檔、正式渠道與兩倉子單編碼、單位換算及零價政策、各倉的覆核人。

**範本驗證（11/24）。** 用 Chromium 將同一檔案上傳至 `main c6df403e` 的隔離合成庫，HTTP 201，預檢為 3 列、2 張、有效 2、無效 0、重複 0。停在「預檢完成」，訂單與預留均為 0。
