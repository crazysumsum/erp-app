## 共用規則

- 只改前端顯示。
- 不改表結構。
- 不改 API 契約。若 X-10 需要新的查詢 API，先交 TL 裁定。
- 既有測試只可更新斷言文字，不刪、不跳過、不放寬。
- 每人一個 PR，內含自己模組的所有項目。
- 每個 PR 都要：
  - 根目錄 `npm run lint`；
  - client build；
  - 兩時區受影響 client 測試；
  - **真瀏覽器 Playwright 驗證受影響頁面**，並附截圖；
  - 非作者 TL 窄核；
  - ci-01 回執登記；
  - 由 PM 開 PR。
- 合併時間：新功能隊列（應收貸項、應付貸項、退款、銷售退貨連結、瀏覽器 CI、F-09）完成之後。分支現在就可以開始做。
- 共用基礎（第一階段）先合併，各模組 PR 隨後逐個合併。
