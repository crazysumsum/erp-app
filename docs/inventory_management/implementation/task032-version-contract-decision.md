Versions are positive unsigned32 values from the caller's current stock read, never silently substituted from historical Movement snapshots. Missing/extra/duplicate/null/string guards reject; a stale version rejects the entire new posting. The server derives every reversed leg, quantity, direction and dimension from the original immutable group; callers cannot partially reverse or retarget it. Missing historical buckets fail closed rather than being recreated. Domain/HTTP replay must still use fresh strong auth before returning the original immutable completed result, not compare an already-completed command with newly changed stock.

This permits reversing an older group after later events only if the actor has reread current stock and all existing free/Reserved/Allocation/Lot/Bin and once-only invariants still hold. The cost is a current stock read and complete version list for callers and future TASK033 UI.
