# 庫存結存與異動 CSV

本次交付對應 2026-11-24 的庫存報表分工。兩份都是數量報表，供倉務下載篩選結果。估值與成本欄位另隨核准的成本資料表及過帳契約交付。

| 入口 | 一列與欄位 | 篩選及排列 |
|---|---|---|
| 庫存總覽 → 匯出結存數量 CSV | 一個倉庫／庫位／SKU／批次／狀態。欄位依序為倉、庫位、SKU 代碼、SKU 名稱、批號、到期日、狀態、基本單位、實存、已分配、庫位可用量。 | SKU 文字／條碼、倉、庫位、批號、庫存狀態、存量、效期，與現行查詢共用。按 SKU 代碼，精確搜尋優先。 |
| 庫存異動 → 匯出異動明細 CSV | 一筆不可變異動。異動編號、UTC 入帳時間、類型、位置類型、倉、庫位、SKU 代碼及名稱、批號、到期日、狀態、入出方向、基本單位數量、異動前後結存、來源模組／單據類型／單號／行。 | 入帳日期範圍、異動類型、來源模組／單據類型／單號、SKU、倉、庫位、批次、操作者，與清單相同。入帳時間及異動編號由新至舊。 |

下載涵蓋全部符合篩選的資料，與畫面頁碼無關。結存明細面板選定 SKU 後，如需限定匯出同一 SKU，請在上方搜尋欄輸入代碼。上限每份 5,000 筆，超過時請按倉、庫位或日期再分批，系統回 422 且不交付部分檔。零筆時 CSV 只有表頭。異動在途列的庫位可空，同一報表允許有批及無批異動。日期仍用查詢頁既有的瀏覽器本地時區換算，CSV 的入帳時間以 UTC 顯示，到期日保留原曆日。

`GET /api/v1/inventory/reports/stocks`、`GET /api/v1/inventory/reports/movements` 使用 `inventory.view`，讀取前後核對目前權限，拒絕頁碼與未知參數。CSV 採 UTF-8 BOM、CRLF，防試算表公式啟動。匯出不寫資料表，不保存暫存 CSV，也不包含成本、內部雜湊或認證資訊。結存是下載時的數量，與分批下載之間的時間差須一併判讀。
