      assert.ok([repo,path.dirname(path.dirname(python)),path.dirname(harness),nodeToolchain,...browserPayloadRoots].some(parent=>realpath===parent||realpath.startsWith(parent+path.sep)),'Unreviewed runtime symlink target');
      files[name] = { symlink: await fs.readlink(name), realpath,
        ...(target.isFile() ? { sha256: sha256(await fs.readFile(realpath)) } : { directory: true }) };
      if (target.isDirectory()) await visit(realpath);
    } else if (info.isDirectory()) {
      const realpath = await fs.realpath(name);
      const children = (await fs.readdir(name)).sort();
      files[name] = { directory: true, children };
      if (seen.has(realpath)) return; seen.add(realpath);
      for (const child of children) await visit(path.join(name, child));
    } else if (info.isFile()) files[name] = { sha256: sha256(await fs.readFile(name)), executable: !!(info.mode & 0o111) };
    else throw new Error('Unsupported runtime input: ' + name);
  }
  await visit(directory); return files;
}

async function resolvedExecutable(name, searchPath = testEnv.PATH) {
  const candidates = name.startsWith('/') ? [name] : searchPath.split(path.delimiter).map(directory => path.join(directory, name));
  for (const candidate of candidates) {
    try {
      await fs.access(candidate, 1); const realpath = await fs.realpath(candidate);
      return { path: candidate, realpath, sha256: sha256(await fs.readFile(realpath)), executable:!!((await fs.stat(realpath)).mode & 0o111),
        symlink: (await fs.lstat(candidate)).isSymbolicLink() ? await fs.readlink(candidate) : null };
    } catch (error) { if (!['ENOENT','EACCES','ENOTDIR'].includes(error.code)) throw error; }
  }
  throw new Error('Executable resolution unknown: '+name);
}

async function bounded(work, ms, label) {
  let timer;
  try { return await Promise.race([work, new Promise((_, reject) => { timer = setTimeout(() => reject(new Error(label)), ms); })]); }
  finally { clearTimeout(timer); }
}
async function launch(executable, args, env, label) {
  const stdoutName = `${label}.stdout.log`, stderrName = `${label}.stderr.log`;
  const stdout = await fs.open(path.join(root, stdoutName), 'wx', 0o600); handles.push(stdout); artifacts.add(stdoutName);
  const stderr = await fs.open(path.join(root, stderrName), 'wx', 0o600); handles.push(stderr); artifacts.add(stderrName);
  report.commands.push({ label, executable, args, cwd: repo, env });
  // The runner may fork a test worker; its fresh process group is owned from spawn.
  const child = spawn(executable, args, { cwd: repo, env, detached: true, stdio: ['ignore', stdout.fd, stderr.fd] });
  const record = { label, child, settled: false, result: null, signals: [], groupTerminal: false }; processes.push(record);
  record.exit = new Promise(resolve => {
    child.once('error', error => { record.spawnError = failure(error); });
    child.once('close', (code, signal) => { record.settled = true; record.result = { code, signal }; resolve(record.result); });
  });
  return record;
}
function groupGone(record) {
  if (!record.child.pid) return record.settled;
  assert.ok(Number.isSafeInteger(record.child.pid) && record.child.pid > 0);
  try { process.kill(-record.child.pid, 0); return false; }
  catch (error) {
    if (error.code === 'ESRCH') return true;
    record.groupError = failure(error); return false;
  }
}
async function groupEnd(record) {
  if (record.groupTerminal) return;
  const deadline = performance.now() + 5000;
  while (!groupGone(record)) {
    assert.ok(performance.now() < deadline, `${record.label} process group disappearance unknown`);
    await delay(25);
  }
  record.groupTerminal = true;
}
async function stop(record) {
  if (record.groupTerminal) return; // A disappeared PGID is never owned again.
  if (record.settled && groupGone(record)) { record.groupTerminal = true; return; }
  cleanupErrors.push(`Normal child completion unproven: ${record.label}`);
  for (const signal of ['SIGTERM', 'SIGKILL']) {
    record.signals.push(signal);
    try {
      if (record.child.pid && !groupGone(record)) process.kill(-record.child.pid, signal);
      await bounded(Promise.all([record.exit, groupEnd(record)]), 5000, `${record.label} ${signal} completion unknown`);
    }
    catch (error) { cleanupErrors.push(error.message); }
    if (record.settled && record.groupTerminal) return;
  }
  record.child.unref();
}

async function stageFloorLcov(repo, bytes, binding, proof) {
  assert.equal(sha256(bytes),binding.lcov_sha256,'Verified CI LCOV bytes required');
  const directory=path.join(repo,'server/coverage'),target=path.join(directory,'lcov.info');
  const snapshot=async filename=>{
    let st;try{st=await fs.lstat(filename);}catch(error){if(error.code==='ENOENT')return{absent:true};throw error;}
    assert.ok(st.isFile()&&!st.isSymbolicLink()&&st.uid===process.geteuid(),'Own regular LCOV required');
    return{dev:st.dev,ino:st.ino,uid:st.uid,mode:st.mode&0o7777,sha256:sha256(await fs.readFile(filename))};
  };
  let madeDirectory=false,backupDirectory,backup,moved=false,staged;
  Object.assign(proof,{kind:'HD235_ORIGINAL_FLOOR_CONSUMPTION',binding,target:'server/coverage/lcov.info',backupRemoved:false});
  let restorePromise;
  const restore=()=>restorePromise??=(async()=>{
    if(staged) {
      const taken=path.join(backupDirectory,'consumed-lcov.info');
      await fs.rename(target,taken);proof.takenTarget=taken;
      let current;
      try {
        current=await snapshot(taken);
        assert.ok(!current.absent&&current.dev===staged.dev&&current.ino===staged.ino&&current.uid===staged.uid,'Staged LCOV replaced; preserve original backup');
      } catch(error) {
        // The moved pathname may be foreign. Return it only without clobbering,
        // otherwise retain it in our unique slot beside the original backup.
        try{await fs.link(taken,target);await fs.unlink(taken);proof.takenTarget=target;}
        catch(returnError){proof.unexpectedReturnError=returnError.code??returnError.message;}
        throw error;
      }
      proof.consumedAfterSha256=current.sha256;proof.consumedAt=new Date().toISOString();
      await fs.unlink(taken); // Only the verified inode in our own slot is removed.
    }
    if(moved)await fs.link(backup,target); // EEXIST preserves a newly created foreign target.
    proof.restored=await snapshot(target);assert.deepEqual(proof.restored,proof.before,'Original LCOV identity/bytes/mode restored');
    if(moved){await fs.unlink(backup);moved=false;}
    if(backupDirectory)await fs.rmdir(backupDirectory);
    if(madeDirectory)await fs.rmdir(directory); // Never remove unrelated coverage files.
    proof.backupRemoved=true;proof.restoredAt=new Date().toISOString();
    if(staged)assert.equal(proof.consumedAfterSha256,binding.lcov_sha256,'Consumed LCOV changed during checker execution');
    return proof;
  })();
  try {
    let directoryState;try{directoryState=await fs.lstat(directory);}catch(error){if(error.code!=='ENOENT')throw error;await fs.mkdir(directory,{mode:0o700});madeDirectory=true;directoryState=await fs.lstat(directory);}
    assert.ok(directoryState.isDirectory()&&!directoryState.isSymbolicLink()&&directoryState.uid===process.geteuid(),'Own coverage directory required');
    assert.equal(await fs.realpath(directory),directory,'Coverage parent link refused');
    proof.before=await snapshot(target);
    backupDirectory=await fs.mkdtemp(path.join(directory,'.hd235-floor-'));backup=path.join(backupDirectory,'original-lcov.info');proof.backupDirectory=backupDirectory;
    if(!proof.before.absent){await fs.rename(target,backup);moved=true;assert.deepEqual(await snapshot(backup),proof.before);}
    const handle=await fs.open(target,'wx',0o600);
    try {
      const st=await handle.stat();staged={dev:st.dev,ino:st.ino,uid:st.uid};
      await handle.writeFile(bytes);await handle.sync();
    } finally {await handle.close();}
    proof.staged=await snapshot(target);proof.consumedBeforeSha256=proof.staged.sha256;
    assert.equal(proof.consumedBeforeSha256,binding.lcov_sha256);
    proof.stagedAt=new Date().toISOString();
    return{proof,restore};
  } catch(error) {
    if(proof.before)try{await restore();}catch(cleanup){error.floorRestorationError=cleanup.message;}
    else if(madeDirectory)try{await fs.rmdir(directory);}catch(cleanup){error.floorRestorationError=cleanup.message;}
    throw error;
  }
}

        report.schemasAfter=(await admin.query('SELECT SCHEMA_NAME FROM information_schema.schemata ORDER BY SCHEMA_NAME'))[0].map(row=>row.SCHEMA_NAME);
        assert.deepEqual(report.schemasAfter,report.schemasBefore,'Original fixture left unknown child schema; do not delete by prefix');
      } catch (error) { cleanupErrors.push(error.message); }
      if (created && sqlTerminal) {
        try {
          await admin.query(`DROP DATABASE ${schema}`);
          assert.equal((await admin.query('SELECT SCHEMA_NAME FROM information_schema.schemata WHERE SCHEMA_NAME=?', [schema]))[0].length, 0);
          dropped = true;
        } catch (error) { cleanupErrors.push(error.message); }
      }
    }
  }
  if (!innerMayBeRunning && admin && !adminStream.destroyed) {
    try { await admin.query('SHUTDOWN'); normalShutdown = true; }
    catch (error) {
      if (['PROTOCOL_CONNECTION_LOST', 'ECONNRESET'].includes(error.code)) normalShutdown = true;
      else cleanupErrors.push(error.message);
    }
  }
  if (!innerMayBeRunning && daemon) {
    try { assert.deepEqual(await bounded(daemon.exit, 10000, 'Daemon shutdown deadline'), { code: 0, signal: null }); }
    catch (error) { cleanupErrors.push(error.message); }
  }
  for (const record of processes) if (record !== daemon || !innerMayBeRunning) await stop(record);
  if (innerMayBeRunning) daemon?.child.unref();
  if (admin) {
    try { if (!adminStream.destroyed) await bounded(admin.end(), 10000, 'Observer end deadline'); }
    catch (error) { cleanupErrors.push(error.message); admin.destroy(); }
    if (!adminClosed) {
      try { await bounded(new Promise(resolve => { if (adminClosed) resolve(); else adminStream.once('close', resolve); }), 10000, 'Observer socket close deadline'); }
      catch (error) { cleanupErrors.push(error.message); admin.destroy(); }
    }
  }
  if (!innerMayBeRunning && leaseRecorded && processes.every(record => record.settled && record.groupTerminal)) {
    try { await stateRuntime(false); } catch (error) { cleanupErrors.push('Runtime checkpoint: '+error.message); }
  }
  for (const handle of handles) try { await handle.close(); } catch (error) { cleanupErrors.push(error.message); }
  report.artifacts = {};
  for (const name of artifacts) {
    try {
      await fs.copyFile(path.join(root, name), path.join(output, name));
      const copied = await fs.open(path.join(output,name),'r');
      try { await copied.sync(); } finally { await copied.close(); }
      report.artifacts[name] = sha256(await fs.readFile(path.join(output, name)));
    } catch (error) { cleanupErrors.push(`${name}: ${error.message}`); }
  }
  // Generic runner owns native diagnostics outside the temporary runtime.
  report.directSuiteArtifacts = {};
  try {
    for (const entry of await fs.readdir(output, { withFileTypes: true })) {
      if (entry.isFile()) report.directSuiteArtifacts[entry.name] = sha256(await fs.readFile(path.join(output, entry.name)));
    }
  } catch (error) { cleanupErrors.push(`direct suite artifact retention: ${error.message}`); }
  try { report.runnerResponse ??= JSON.parse(await fs.readFile(path.join(root,'harness-runner.stdout.log'),'utf8')); } catch {}
  report.processes = processes.map(record => ({ label: record.label, pid: record.child.pid ?? null,
    settled: record.settled, groupTerminal: record.groupTerminal, groupError: record.groupError ?? null,
    result: record.result, spawnError: record.spawnError ?? null, signals: record.signals }));
  report.terminal = { sqlTerminal, dropped, normalShutdown, observerSocketClosed: adminClosed, observerSocketDestroyed: adminStream?.destroyed ?? null };
  const workersKnown = processes.every(record => record.settled && record.groupTerminal && !record.spawnError && record.signals.length === 0);
  const lifecycleKnown = workersKnown && (!needsMysql || (created && dropped && sqlTerminal && normalShutdown && adminClosed && adminStream.destroyed && daemon?.result?.code === 0 && daemon?.result?.signal === null));
  if (!lifecycleKnown) cleanupErrors.push('Complete normal lifecycle unproven; retain exact owned root');
  if (cleanupErrors.length) report.status = 'FAIL';
  report.cleanup = cleanupErrors.length ? 'UNKNOWN_OWN_ROOT_RETAINED' : 'EXACT_ROOT_READY_FOR_REMOVAL';
  report.cleanupErrors = cleanupErrors;
  report.finishedAt = new Date().toISOString();
  // Evidence must be durable before deleting only this validated, unsymlinked mkdtemp root.
  try {
    await durableJson('pre-removal-observation.json',report);
    if (!cleanupErrors.length) {
      assert.equal(path.dirname(root), '/private/tmp');
      assert.ok(root.startsWith(rootPrefix)); assert.match(root.slice(rootPrefix.length), /^[A-Za-z0-9]+$/u);
      assert.equal(await fs.realpath(root), root); assert.equal((await fs.lstat(root)).isDirectory(), true);
      await fs.rm(root, { recursive: true }); report.cleanup = needsMysql ? 'OWN_SCHEMA_DROPPED_NORMAL_DAEMON_EXIT0_EXACT_ROOT_REMOVED' : 'OWN_FILES_ROOT_REMOVED';
      await durableJson('observation.json',report);
    }
  } catch (error) {
    cleanupErrors.push(error.message); report.status = 'FAIL'; report.reportOrRemovalError = failure(error);
    report.cleanup = 'EVIDENCE_OR_ROOT_REMOVAL_FAILED';
    try { await durableJson('observation.json',report); } catch {}
  }
  await durableJson('observation.json',report);
  if(['OWN_SCHEMA_DROPPED_NORMAL_DAEMON_EXIT0_EXACT_ROOT_REMOVED','OWN_FILES_ROOT_REMOVED'].includes(report.cleanup))await publishReceiptReferences('runtime-complete-ref.json','observation.json');
  console.log(JSON.stringify({ output, root, status: report.status, cleanup: report.cleanup,
    error: report.error ?? null, cleanupErrors, reportOrRemovalError: report.reportOrRemovalError ?? null }));
}
if (primary || report.status === 'FAIL') process.exitCode = 1;
