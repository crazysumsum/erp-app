## 3. TL裁定（技術預設，非作者評審核對；Sam如有不同意見可隨時指出）

1. 非港幣採購單的收貨在成本啟用後不可確認（409）（Codex TL `5c40ccfc`）。
2. 成本池在Inventory鎖序的最後取得（5.2）。
3. 沖銷及退回按原值；退回供應商在池內金額不足時以池內金額為限，差額記在流水上（5.1）。
4. 正調整及盤盈按當時平均成本入池，不另填成本（`inventory.md`主張另填核准成本；作者取較簡單的做法）。
5. 收貨沖銷與退回供應商共用「合計不超過實收」的上限（6.2）。
6. 貸項核銷計入發票現有的`allocated_amount`，不加發票欄（7.4；與`returns.md`的建議不同）。
7. 沒有原成本時按當時平均成本；出庫超過計價數量時池歸零並記未計價數量（5.1）。

使用者看得到的規則不在這裡，在第4節決定D由Sam決定。

### 決定A：returns-01一人的工作量超出上線日期，怎樣處理

- **背景**：各負責人的估計（單人、從表批准起算）：成本7–11人日；出貨沖銷5–8日；收貨沖銷4–6人日；退貨、兩側貸項及退款合計18–28人日（returns-01一人）。11-27前各頁一致只能完成不需新表的報表。以11-25為第1個工作天、不計11-26驗收日、週末及公眾假期按工作日推算（作者的推算，不是量度）：9人日約到12-08，15人日約到12-16，18人日約到12-21，28人日到1月初；這還未計評審、CI、合併及第二輪驗收。**所以returns-01一人做完全部，趕不上12月中上線。**
- **選項**
  - **A（建議）**：再指派一位負責人做應收及應付的貸項單和退款（10–15人日），returns-01只做兩側實物退貨（8–13人日）。兩人並行，最長的鏈約8–15人日，約12-07至12-16完成開發自測。
  - **B**：不加人，把退回供應商、應付貸項單及供應商退款（約9–13人日）延到上線之後；returns-01上線前只做客戶退貨、應收貸項及客戶退款（9–15人日，約12-08至12-16）。上線初期供應商一側以改價、作廢重開及系統外紀錄處理。
  - **C**：不加人也不延後，接受完成日在12月下旬至1月初，上線日相應推遲。
- **建議**：A。

### 決定D：五條使用者看得到的規則

- **背景**：下列各條會改變使用者的做法，作者取了最簡單的做法，但須Sam接受。
  1. 已在應收發票上（草稿或已確認）的出貨不可沖銷：先取消或作廢發票（作廢須先解除核銷）再沖銷；貨已到客戶手上的走客戶退貨及貸項（`SCOPE.md` 6.1）。另一做法是以貸項放行（AR r3的來源證明），約多2–3日。
  2. 退款只可從貸項單的可用額付出或收回；未核銷的收款（預收款）的退款屬第二期；供應商退回預付款本輪不做（7.5）。
  3. 退回供應商不改應付發票：應付仍按整張收貨的實收數量開票；若供應商發票已扣除退貨，入帳人員以改價對齊，或先照收貨開票再以應付貸項單沖減（7.3）。
  4. 期初應收發票沒有發票行，可開不引用發票行的貸項，但不計入按SKU的毛利（7.4）。
  5. 毛利報表只計港幣發票，非港幣發票另列為「未計毛利」（第8節）。
- **選項**：**A（建議）**全部接受；**B**指出哪一條要另行處理。
